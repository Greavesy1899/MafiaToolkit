## How to contribute

1. Fork the repository and create a topic branch from `master`.
2. Make your change. Match the style and conventions of the surrounding code.
3. Build and test locally (see [`CLAUDE.md`](CLAUDE.md) / the README for build
   instructions).
4. Open a pull request against `master` describing what you changed and why.
